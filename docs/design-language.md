# Design language

Kaji uses one visual language: Mono in black, white, and gray, with light and dark variants that follow the system appearance.

The interface should read as a quiet native menu-bar utility. It favors compact hierarchy, restrained contrast, small corner radii, and dense but legible information. Color is not used to manufacture urgency or distinguish product themes.

## Rules

- Use neutral grayscale tokens for backgrounds, surfaces, text, tracks, values, and selection.
- Support both system light and dark appearance.
- Reserve stronger contrast for real pressure or an action that needs attention.
- Avoid decorative gradients, glows, saturated accents, and dashboard styling.
- Preserve each module's natural information form. A shared shell does not require every signal to become the same chart.

Mono is a product constraint rather than a selectable theme. New UI should not introduce an alternate color language.
