# Spec: Goal Tags

Status: approved

## Goal

每个 Flexible、Fixed、Vision 项都可选择一个黑白符号类别，用简短类别区分 Health、Work 等上下文。

## In

- 提供 6 类：Work 方块、Health 圆、Home 菱形、Learn 三角、Admin 六边形、Personal 星。
- Today、Week、Vision 新增或已有项目都可从行内菜单选择。
- Fixed 每个星期模板拥有一个 Tag；默认训练模板为 `Health`。
- Tag 以标题前方的 `10pt` 空心 mono 符号显示，不常驻显示类别文字。
- Flexible 项点击符号完成：完成后符号变实心、标题变灰并加删除线，原顺序不变。
- Tag 随 Goal 保存、迁移、昨日未完成转移与周状态刷新保留。
- 旧数据缺少 Tag 时按标题关键词自动分类；无法判断时使用 Personal。
- Tag 不影响完成数、筛选、排序、Break Vision 选择和菜单栏。

## Behavior

- 点击 `+` 后创建空标题、Personal，并聚焦标题。
- 点击分类符号的菜单可切换 6 项类别；Flexible 符号的主操作是完成/取消完成。
- Fixed Tag 在侧边设置编辑器中随星期模板选择。

## Non-goals

- Tag 颜色自定义、自由文本、筛选器、自动补全、全局 Tag 管理。
- 多 Tag；每项本轮只支持一个 Tag。

## Acceptance

| Case | Given | Expected | Verify |
| --- | --- | --- | --- |
| T1 | 解码旧 Goal JSON | Tag 为空，其他数据不变 | 自动 |
| T2 | 新增 Today / Week / Vision | 可直接填写标题与 Tag，重启保留 | 自动模型 + 人工 smoke |
| T3 | 昨日未完成转到今天 | Tag 保留 | 自动 |
| T4 | 编辑 Fixed 某天 Tag | Goals 当天 Fixed 行显示该 Tag | 自动模型 + 人工 smoke |
| T5 | 完成 Flexible | 分类符号变实心、标题删除线、任务不重排 | 人工 smoke |

## Done

自动迁移测试、状态测试与 Light / Dark smoke 通过。

## Rollback

Tag 字段为向后兼容可选数据；旧版本忽略未知字段。

## 批准前必读

- 本轮每项只有一个 Tag，避免 Tag 管理系统膨胀。
- Tag 完全不参与逻辑，只提供视觉上下文；不会筛选或改变统计。
- Fixed Tag 属于星期模板，不属于内部训练动作。
