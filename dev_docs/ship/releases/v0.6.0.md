# v0.6.0 — Lean module host

Kaji is no longer “install once, get everything.”

Default should feel **small and quiet** again: quota rings first. Work / System / Goals are **opt-in modules**. Modules exist so the product can get small — not so it can grow forever.

This answers real user signal: *latest updates piled on too much; I rolled back.*

## Highlights

- **Slim default** — fresh / migrated installs enable **Quota only**. Turn Work, System, or Goals on in Settings → Modules.
- **Disabled = gone** — no popover page, no leftover timers/polls (work session + system monitor stop when off).
- **Mono only** — black / white / gray light & dark. Color theme toggle removed.
- **Work countdown slot** — when Work is on, menu bar can show focus/break remaining next to the rings (no noisy `BREAK` label).
- **Internal docs** — product / design / specs live under `dev_docs/` (not a public docs site). Specs under `dev_docs/specs/`.

## Install

Prefer building from this tag (unsigned builds + browser zip downloads fight Gatekeeper):

```sh
curl -fsSL https://raw.githubusercontent.com/blackblue-labs/kaji/main/install.sh | bash
```

Or clone the tag and run `./scripts/build-local.sh`.

## Not in this release

- Ice / Bartender-style hiding of other menu-bar apps
- Downloadable third-party plugins
- Notarized / Developer ID signed binaries
