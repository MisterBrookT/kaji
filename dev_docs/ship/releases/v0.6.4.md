# v0.6.4 — Fixed goals + lightweight categories

Goals now combines flexible tasks, a weekday fixed plan, and long-term Vision
in one quiet surface.

## Highlights

- **Fixed plan** — edit weekday templates in Settings and complete today's
  plan as one goal; hover it to inspect the full routine.
- **Vision** — long-term directions stay visible without Todo completion
  semantics.
- **Lightweight categories** — Work, Health, Home, Learn, Admin, and Personal
  use small monochrome outline symbols instead of a separate tag column.
- **Clear completion state** — completed flexible goals use the filled category
  symbol and a struck-through title while preserving their original order.
- **Unified progress** — the menu-bar calendar count includes today's flexible
  goals and fixed plan.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/blackblue-labs/kaji/main/install.sh | bash
```

Or clone the tag and run `./scripts/build-local.sh`.

## Notes

- Existing goal data remains compatible; missing categories are inferred once
  from the title and then persisted.
- No notarized binary is attached; the installer builds locally.
