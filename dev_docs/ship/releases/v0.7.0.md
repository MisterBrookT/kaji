# v0.7.0 — Goals, AI News, and clearer settings

Kaji 0.7 brings richer opt-in modules while keeping the default menu bar quiet.
Goals now supports the full planning loop, AI News adds a low-friction view of
the current AI HOT Top 10, and Settings separates module behavior more clearly.

## Highlights

- **Unified Goals creation** — create Today, Week, Vision, or repeating Schedule
  goals from one adjacent popover.
- **Schedule goals** — select multiple weekdays, add optional notes, preserve
  completion across the existing Goals state model, and migrate prior Fixed data.
- **Lighter goal tags** — four compact circle/rectangle states with consistent
  icons across existing and newly created goals.
- **AI News module** — an opt-in menu-bar entry for AI HOT Top 10 with local
  caching, read state, configurable refresh cadence, and source-aware summaries.
- **Fast contextual hover** — news and goal details stay reachable, switch
  quickly between rows, and remain anchored beside the relevant item.
- **Disk insight** — read-only disk categories with a 24-hour scan cache and
  clear GB/MB formatting.
- **Settings navigation** — standard resizable macOS settings window with
  separate Quota and AI News sections; Goals retains a future settings slot
  without duplicating content management.

## Safety and compatibility

- AI News is off by default and uses AI HOT's anonymous read-only v1 API.
- Disk insight is read-only and never silently deletes user files.
- Existing Fixed plans migrate to Schedule goals; existing Goals state remains
  the source of truth.
- Quota polling remains unchanged. The hour-based setting applies only to AI
  News.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/blackblue-labs/kaji/main/install.sh | bash
```

The installer checks out this release tag and builds locally. No unsigned
browser `.app.zip` is attached.
