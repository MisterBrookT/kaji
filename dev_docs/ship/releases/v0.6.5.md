# v0.6.5 — Goals state cleanup

Goals now uses one current state only. Old Daily Goals compatibility data can
no longer reappear when the current state is absent or damaged.

## Highlights

- **Single source of truth** — only `goalHorizonStateV1` is loaded.
- **No legacy resurrection** — old `dailyGoals*` keys are removed and never
  imported.
- **Safe valid-state loading** — an existing valid current state is read
  without rewrite.
- **Explicit recovery** — missing state starts empty; corrupt state is backed
  up with diagnostic metadata before an empty recoverable state is created.
- **Persistence coverage** — isolated UserDefaults tests cover first load,
  repeat launch, legacy cleanup, corruption, invalid types, and day rollover.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/blackblue-labs/kaji/main/install.sh | bash
```

Or clone the tag and run `./scripts/build-local.sh`.

## Notes

- Corrupt-state backups are retained for diagnosis and are not automatically
  restored or deleted.
- No notarized binary is attached; the installer builds locally.
