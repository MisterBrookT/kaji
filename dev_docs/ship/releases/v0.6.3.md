# v0.6.3 — Goals + calm break

Kaji now gives Goals a quiet, always-available menu-bar surface and replaces
the old break theater with calm Japanese landscape scenes.

## Highlights

- **Three goal horizons** — manage Today, This Week, and Long Term goals in one
  scrollable popover without switching tabs.
- **Menu-bar progress** — the compact `completed/total` label shows today's
  progress and opens Goals directly.
- **Direct module entry points** — Quota rings, Work countdown, and Goals
  progress each open their own page; clicking the active slot closes it again.
- **Yesterday pending** — unfinished daily goals move out of Today at the day
  boundary and can be restored or dismissed explicitly.
- **Calm break scenes** — four Japanese nature scenes replace the panda and
  exercise-heavy break screen.
- **Popover stability** — direct module entry and normal page navigation now
  share the same AppKit placement path, fixing the shifted-content regression.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/blackblue-labs/kaji/main/install.sh | bash
```

Or clone the tag and run `./scripts/build-local.sh`.

## Notes

- System and Goals remain opt-in modules.
- No notarized binary is attached; the installer builds locally.
