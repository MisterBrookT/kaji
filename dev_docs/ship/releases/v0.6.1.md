# v0.6.1 — Cursor quota rings

Cursor joins Claude / Codex as a first-class menu-bar provider: **outer API / inner Auto** from the current billing cycle.

Today tokens / cost / sparkline stay **Claude·Codex-only** — Cursor’s API does not expose a trustworthy daily token total, so the popover quietly omits those fields instead of faking zeros.

## Highlights

- **Cursor provider** — reads local Cursor login token, fetches period usage (unofficial DashboardService), maps to dual rings.
- **Labels** — Cursor shows **API / Auto**, not 5h / 7d.
- **Default visible** — same level as Claude / Codex (one-shot upgrade insert; you can turn it off).
- **Limits-only row** — no today token count, no estimated cost, no sparkline for Cursor; Today / Cost summary only sums providers that actually have daily data.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/blackblue-labs/kaji/main/install.sh | bash
```

Or clone the tag and run `./scripts/build-local.sh`.

- Estimating Cursor “tokens today” from local transcripts
